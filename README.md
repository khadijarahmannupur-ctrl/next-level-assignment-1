# Assignment: Problem Solving with TypeScript & OOP

## Overview

This assignment focuses on practicing core TypeScript concepts from Modules 1, 2, and 3.

The coding section includes 8 problems covering basic types, optional parameters, type narrowing, readonly tuples, generics, interfaces, OOP, and asynchronous Promises.

All coding solutions are implemented in a single file named `solutions.ts`.
